XyloKerf Support

Need help with projects, material presets, cut plans, PDF/CSV exports, or app settings? Use this page to get unstuck.

Common fixes

  • Cut plan will not calculate: Check that each part has valid dimensions and an existing material.
  • Parts do not fit: Increase stock quantity, choose larger stock, reduce kerf, or allow rotation when grain direction permits.
  • PDF/CSV export: Open a calculated cut plan, then use the PDF or CSV export buttons. Export requires XyloKerf Pro.
  • Project limit: Free includes three active projects. Archive older projects or upgrade to XyloKerf Pro for unlimited active projects.
  • Restore purchase: Open Settings → Subscription → Restore Purchases.
  • Manage or cancel: Open App Store account subscriptions from XyloKerf Settings or the App Store app.
  • Reset local data: Open Settings → Data → Delete all local data.

Contact support

Report issues or request help through GitHub Issues. Please include your iOS version, app version, and a short description of what happened.
